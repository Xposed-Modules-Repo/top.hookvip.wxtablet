## 模块功能

+ ~~禁用 **TencentTinker** 热补丁~~
+ 强制开启微信平板模式
+ 强制显示平板登录按钮(高版本)

## 适配范围

+ 理论支持`8.0.40`以上的**所有版本(国内/Play版本)**

## 测试版本

- `8.0.40` `8.0.45` `8.0.50` `8.0.53` `8.0.56`
- `8.0.57` `8.0.58` `8.0.60` `8.0.61` `8.0.62`
- `8.0.74` `8.0.76` `8.0.77` `8.0.78` `8.0.79`

**以上版本均经过测试 且运行情况良好**

## 模块特色

1. 无视**Tinker**热修复 不必担心模块失效
2. 多次重启微信/随意升降级版本 都不会出现掉线的情况
3. 不卡启动页 自带配置缓存 无需多次调用Dexkit查询
4. 聊天页 长按发送语音 使用原版布局
